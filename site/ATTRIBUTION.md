# Card artwork

This project uses the original Rider–Waite–Smith tarot illustrations by Pamela Colman Smith, first published in 1909–1910. The source artwork is in the public domain. The web-sized files in `cards/` were derived from public-domain scans collected by the `mixvlad/TarotCards` project and Wikimedia Commons.

- https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck
- https://github.com/mixvlad/TarotCards
